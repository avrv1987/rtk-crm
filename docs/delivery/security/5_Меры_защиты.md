# 5. Меры защиты: что реализовано в продукте

Меры сгруппированы по группам приказа ФСТЭК России от 18.02.2013 № 21 (состав и содержание мер для ИСПДн). Для каждой группы указано: что реализовано в продукте (с путём к коду или конфигурации), что закрывается организационно у оператора и что не покрыто. Колонка «Проверено» называет фактически выполненные проверки: «тесты» означает автоматические тесты backend (`cd backend && mvn test`), «стенд» — проверку на запущенном Docker-стенде.

Таблица включает меры модуля «Слушатели» (пути к коду ниже сверены с фактическим состоянием репозитория, включая процессы, API и экран раздела «Зачисление»: приём оплат, правка анкеты, заполненный шаблон, файл для LMS).

Пути к Java-коду backend даны относительно `backend/src/main/java/ru/rtk/crm/`, остальные — от корня репозитория.

## 5.3. Итог

Продукт реализует технические меры базового уровня: аутентификацию через Keycloak, серверную проверку прав в каждом запросе к данным, CSRF, защищённые cookie, TLS в публикационном варианте, заголовки безопасности (CSP, HSTS при HTTPS и другие) на каждом ответе, антивирусную проверку файлов, журналы действий, пределы нагрузки, резервное копирование с проверенным восстановлением и шифрованием копий, второй фактор входа для администратора и оператора зачисления. Для УЗ-4 по ПП РФ № 1119 дополнительно нужны организационные меры оператора (помещение, носители, перечень лиц). До работы с реальными ПДн нужно устранить пробелы продукта из раздела 6.10 и решить вопросы раздела 3.4. Соответствие 152-ФЗ и приказу ФСТЭК № 117 документом не подтверждается.

Модуль «Слушатели» добавляет: шифрование каждого поля анкеты на уровне приложения с AAD и версией ключа, отпечатки HMAC для поиска без расшифровки, доступ только по флагу «Оператор зачисления» с проверкой на каждом запросе, отдельную категорию журнала `LEARNER` без значений ПДн, маскирование в интерфейсе с раскрытием по группе, срок хранения с обезличиванием по расписанию, приём оплат и заполненного шаблона, перенос зачислений и выгрузку файла для LMS — раздел «Зачисление» (реестр мер, раздел 6.9).
