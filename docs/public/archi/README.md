# Модель архитектуры в Archi

Файл `rtk-crm.archimate` — редактируемая модель CRM ИТ Школы РТК в формате инструмента Archi. Она описывает функциональную и компонентную архитектуру, развёртывание и дополнительные модули системы. Обзор архитектуры в текстовом виде — [Архитектура.md](../Архитектура.md).

## Как открыть

1. Установите Archi 4.9 или новее с официального сайта <https://www.archimatetool.com/download/> (бесплатно, Windows, macOS, Linux).
2. В Archi выберите **File → Open…** и укажите файл `rtk-crm.archimate`.
3. В дереве **Models** раскройте модель «CRM ИТ Школы РТК», затем папку **Views** и дважды щёлкните нужное представление.

Изображение представления: открыть его и выбрать **File → Export → View As Image…** (PNG или SVG). Полный HTML-отчёт по модели: **File → Report → HTML…**.

## Представления

| Представление | Что показывает |
|---|---|
| Функциональная архитектура | роли пользователей, процесс работы с вузом из 14 шагов, назначение менеджера, отчётность, прикладные сервисы и связи между ними |
| Компонентная архитектура | интерфейс на React, nginx, серверное приложение и его модули по пакетам `ru.rtk.crm.*`, PostgreSQL, Keycloak, ClamAV, Moodle и сайт; интерфейсы REST, OIDC, JDBC; сервер с Docker Engine и Compose |
| Развёртывание | контейнеры Docker Compose, их образы, конфигурация и тома, отличия публикационного варианта, отдельный проект демонстрационного Moodle |
| Соглашения, вендоры, «Слушатели» и публикация за прокси | пакеты соглашений, журнала, персональных данных, обучения, модуль «Слушатели», роль «Руководство», общий обратный прокси |

У модулей в свойствах (вкладка **Properties**) указан каталог исходного кода. Пояснения к элементам — во вкладке **Documentation**.

## Как проверен файл

Структуру файла проверяет скрипт на Python (только стандартная библиотека): XML разбирается без ошибок, идентификаторы уникальны, у каждой связи источник и цель существуют, а тип связи входит в перечень ArchiMate 3.1, объекты и линии диаграмм ссылаются на существующие элементы и связи. Скрипт не проверяет таблицу допустимых пар «тип источника — тип связи — тип цели» и размещение вложенных объектов в границах родителя: для этого модель нужно один раз открыть в Archi и сохранить.
