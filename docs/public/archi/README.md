# Модель архитектуры в Archi

Файл `rtk-crm.archimate` — редактируемая модель CRM ИТ Школы РТК в формате инструмента Archi. Она описывает функциональную и компонентную архитектуру, развёртывание и дополнительные модули системы и соответствует версии 2.5.3. Обзор архитектуры в текстовом виде — [Архитектура.md](../Архитектура.md).

## Как открыть

1. Установите Archi 4.9 или новее с официального сайта <https://www.archimatetool.com/download/> (бесплатно, Windows, macOS, Linux).
2. В Archi выберите **File → Open…** и укажите файл `rtk-crm.archimate`.
3. В дереве **Models** раскройте модель «CRM ИТ Школы РТК», затем папку **Views** и дважды щёлкните нужное представление.

Изображение представления: открыть его и выбрать **File → Export → View As Image…** (PNG или SVG). Полный HTML-отчёт по модели: **File → Report → HTML…**.

## Представления

| Представление | Что показывает |
|---|---|
| Функциональная архитектура | роли пользователей, процесс работы с вузом из 14 шагов, назначение менеджера, отчётность, прикладные сервисы и связи между ними |
| Компонентная архитектура | интерфейс на React, nginx, серверное приложение и его модули по пакетам `ru.rtk.crm.*`, PostgreSQL, Keycloak, ClamAV, Moodle и сайт; интерфейсы REST, OIDC, JDBC; сервер с Docker Engine и Compose |
| Развёртывание | контейнеры Docker Compose, их образы, конфигурация и тома, отличия публикационного варианта, отдельный проект демонстрационного Moodle |
| Соглашения, вендоры, «Слушатели» и публикация за прокси | пакеты соглашений, журнала, персональных данных, обучения, модуль «Слушатели», роль «Руководство», общий обратный прокси |
| Контроль, договор, интеграции, роли и профили Compose | «Контроль» работы менеджеров, версии маршрута, договор с вузом, рынок труда, обмен с CRM заказчика, кабинет вуза, роль сотрудника из Keycloak, профили Compose и демонстрационные источники |
| Подключаемые модули — MCP, MAX, почта | сервер MCP для ИИ-агентов с планами изменений, которые подтверждает сотрудник; бот и мини-приложение MAX; уведомления, сводки и приглашения по почте; внешние системы и узлы этих модулей |
| Маршрут и аналитика — виды, свойства этапов, путь вуза, индекс востребованности | виды взаимодействия и правила выбора вида, свойства этапов и нормативы, сводка версий маршрута, путь вуза и матрица «программа × этап», режимы «Сейчас» и «За период», сравнение периодов, индекс востребованности программ |
| Договоры, люди и часы, слушатели и кабинет вуза | отчётность по соглашениям (атрибуты мероприятий, справочники, ставки, перечни с согласованием, сроки отчётного цикла, шаблон выгрузки), учёт людей и часов с передачей сведений в ФРДО, запросы вузу и ответы координатора, зачисление слушателей и перенос в Moodle, роль «Менеджер учебного процесса» |
| Администрирование, ПДн и эксплуатация | настройки системы, состояние модулей, импорт из Excel и CSV с историей, обращения субъектов персональных данных и согласия, ограничение частоты запросов, резервное копирование по расписанию с хранением копий вне сервера |

У модулей в свойствах (вкладка **Properties**) указан каталог исходного кода. Пояснения к элементам — во вкладке **Documentation**.

## Как проверен файл

Структуру файла проверяет скрипт на Python (только стандартная библиотека): XML разбирается без ошибок, идентификаторы уникальны, у каждой связи источник и цель существуют, а тип связи входит в перечень ArchiMate 3.1, объекты и линии диаграмм ссылаются на существующие элементы и связи. С таблицей связей из установленного Archi скрипт проверяет и допустимость каждой пары «тип источника — тип связи — тип цели». Файл открыт и сохранён в Archi 5.10 без ошибок, все связи допустимы. Часть представлений разложена сеткой по слоям; для печати их удобно доразложить вручную.
